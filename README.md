# Тема проекта:

**Система управления складом аптеки.**
- <u>Ведение справочников</u>: Группы лекарств, Лекарства, Производители, Поставщики.
- <u>Функции</u>: ведение справочников, учёт прихода и продаж лекарств. 
- <u>Выходные документы</u>: Отчёт по наличию лекарств на складе по группам, Отчёт по продажам по группам, Счёт-фактура.
